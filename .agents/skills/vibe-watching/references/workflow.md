# 转录、证据与并行工作

## 最小工作记录

为课程使用独立临时目录；记录原课身份与上传版本的对应关系。每讲至少保留：

```json
{
  "lecture": 3,
  "title": "原始讲题",
  "source_id": "平台标识",
  "duration_seconds": 1200,
  "status": "transcribed",
  "transcript": "03.srt",
  "evidence": [
    {
      "start_seconds": 240,
      "end_seconds": 310,
      "cue": "画面中的类名或课件标题",
      "claim": "这一段实际演示什么",
      "checked_against": "subtitle-and-slide"
    }
  ]
}
```

这是字段示意，不是可复用的真实课程数据。状态需要区分目录已核对、已转录、已读、画面已核对、已成稿、已复核，避免“下载成功”被当成“理解完成”。

## 获取与核对

- B 站公开元信息可以来自 `https://api.bilibili.com/x/web-interface/view?bvid=…`。检查返回业务状态，再读取 `pages`；`ugc_season` 是所属合集，不能直接替代当前 BV 的分集范围。
- 使用可用下载器或站点提供的媒体入口，仅获取本任务需要的内容。出现访问限制时使用正常可访问的回放或用户已有材料，不把元信息摘要冒充音频转录。
- 有字幕时先验证字幕语言、范围与原视频一致。仅因它是自动字幕，不必重新转录整门课；在术语、推导或缺失片段处回查原音频。
- 在调用会自动清理的转录工具之前，确认它能返回时间轴，或能在本任务所需的复核阶段临时保留 SRT。不能等到只返回纯文本后才索取已被删除的字幕；若工具不提供保留能力，使用可控的转录流程。用户要求的时间证据尚未复核时，不启动会销毁唯一证据的默认清理。
- 本地 ASR 可将音频转换为 16 kHz 单声道 WAV，并同时输出 SRT 和文本。先拿一小段验证模型语言、术语识别和速度，再安排长课任务。命令参数以当前工具帮助为准。
- 比较最后一条字幕结束位置与视频时长，尾部静音不一定是缺失；差距明显时检查日志与尾部内容。完整时长也不能证明中间没有漏段，需检查异常空白、长重复及语言切换。
- 用较低清晰度取得课件概貌，在需要读代码时提高关键帧清晰度。固定间隔采样容易漏掉短暂修正，重要推导应结合字幕时间补采，而非盲目增大整门课截图数量。
- 英文标识符、模板参数和图中箭头经常被 ASR 破坏。优先依据代码/PPT，再结合上下文校正。把最终版本与演示中的错误尝试区别开，保留有教学意义的纠错过程。

## 时间索引辅助脚本

```bash
python3 .agents/skills/vibe-watching/scripts/index_srt.py /tmp/course/03.srt \
  --bvid BVxxxxxxxxxx --page 3 --duration 1200 \
  --output /tmp/course/03-index.json
```

替换真实 BV、分集和时长。输出中的时间保持原 SRT 坐标，链接使用整数秒；不要把跨讲时间累计值用于某一分 P。若下载的是剪辑片段，须先恢复到原视频坐标，不能直接将片段相对时间发布为整集时间。

证据状态区分“字幕内部坐标，未对齐视频”和“已按该回放版本核对”。前者可以用于查找候选段落，不能直接标为已验证的回看时间。

脚本接受 UTF-8 SRT，报告格式错误和时长越界；它不能确认字幕对应视频、内容是否正确或跳转是否被播放器接受。某些视频版本会有轻微时间漂移，需人工对齐典型开头/中间/结尾片段。

## 并行与恢复

用户授权使用 subagent 时，可按连续讲次划分转录阅读任务，再根据全课证据重新分配文章主题。转录按章节拆分是调度策略，文章不必沿用这个拆分。每个 agent 返回来源、时间证据、讲解主线、重要修正与未确定点，主代理统一消重和安排跨篇联系。

下载和本地转录会竞争网络、CPU、内存。限制并发到机器可承受的水平；多开 agent 不代表每个 agent 都需要同时启动 ASR。共用清单登记谁正在处理哪个分集，避免重复转录及彼此删除临时文件。

长任务按讲保存进度和证据后再进入下一讲。失败时只重试失败分集；同一访问或工具错误连续出现且没有新路径时停止该路径，说明缺口。不要为“全部完成”掩盖错误，也不要在文章和时间表尚未复核前清空唯一的 SRT。

全课重点与文章分组明确后并行写作，每篇只由一名 agent 编辑，其他 agent 可交叉审核。统一术语、来源卡和系列目录。课程名、作者和版本核对可以独立于转录进行。

清理只针对本任务创建的下载文件与转换中间件，不删除用户提供的原视频、字幕或既有资料。保留输出时记录用途和校订状态，避免下一轮把自动稿误当成已核实正文。
